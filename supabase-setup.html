OWNER CONFIGURATION

Hubungkan Supabase

Tempel URL dan Publishable/anon key di sini. Halaman ini membuat file config.js untuk kamu unduh dan pasang ke project.

Jangan masukkan service_role key atau secret key di website frontend.

Setelah file terunduh

  1. Buka repository project di GitHub lewat HP.
  2. Buka file config.js, pilih Edit, lalu ganti seluruh isinya dengan isi file yang baru diunduh (atau unggah/ganti file config.js tersebut).
  3. Commit perubahan dan tunggu Vercel selesai deploy.
  4. Buka /admin.html untuk login staf. Jalankan SQL dari supabase/schema.sql di Supabase SQL Editor terlebih dahulu.

Form ini tidak mengirim key ke server; file dibuat langsung di browser. Nilai URL dan key tetap harus dipasang ke project dan di-deploy agar berlaku untuk semua pengunjung.
